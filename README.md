# REBASE — Modern one-page site (with logo)

## Run
Open `index.html` in a browser.

## Logo
- `assets/logo.svg` is the primary logo (best quality).
- `assets/logo.png` is a fallback.
- `assets/favicon.png` is the tab icon.

## Customize
- Update email/phone in `index.html`
- Adjust colors at the top of `styles.css` (variables --a/--b/--c)

## Deploy
Upload the folder to any static host (S3, CloudFront, Netlify, Vercel, etc.).
